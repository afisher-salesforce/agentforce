2. The sign-in page component (App.tsx) — what React mounts into #root at /sign-in:

function SignInPage() {
  return (
    <div className="flex min-h-[100dvh] items-center justify-center bg-background px-4 py-12">
      <SignIn
        routing="path"
        path="/sign-in"
        signUpUrl="/sign-up"
      />
    </div>
  );
}

The <SignIn> component is Clerk's pre-built widget — it injects its own shadow DOM, styles, and JavaScript bundle at runtime, which is what produces the branded card you see in the screenshot. There's no static HTML equivalent of that card; it only exists after JavaScript executes.
